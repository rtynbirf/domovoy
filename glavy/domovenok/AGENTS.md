# AGENTS.md

Instructions for AI coding agents working in this repository.

## Project overview

domovenok — командный центр дома: задачи, комнаты, расходы и индекс порядка.
Next.js 16 · TypeScript · Prisma · Vitest · зелёный CI как заявка в описании —
держать её правдой: красный CI лечится в той же сессии.

## Commands

- Сборка/тесты: смотри `package.json` (bun.lock — пакетный менеджер bun),
  тесты — Vitest (`vitest.config.ts`), схема БД — `prisma/`.
- Перед коммитом прогонять доступные проверки (lint/test), следовать
  паттернам уже существующих файлов.

## Conventions

- Минимальные, сфокусированные изменения; одна логическая мысль — один коммит
  (формат `тип(область): суть по-русски`).
- Никогда не коммитить секреты, токены, ключи: секреты живут в локальных файлах вне git-слежки.
- README.md обновлять при изменении поведения или структуры.
- Перед коммитом прогонять доступные проверки; зелёный CI — закон дома
  (устав: `rtynbirf/repo-doctrine`).
- Правило аддитивности: добавлять можно; удалять чужое и переписывать историю — нельзя
  (откат — только `git revert`, никогда force-push).
