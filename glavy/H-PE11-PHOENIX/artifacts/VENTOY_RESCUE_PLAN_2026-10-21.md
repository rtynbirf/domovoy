## ЛЕЧЕНИЕ — 2 ШАГА

ШАГ 1 — штатный Upgrade до 1.1.18 (у вас уже скачан ventoy-1.1.18-windows.zip):
1. Распаковать zip на любой диск
2. Ventoy2Disk.exe → выбрать флешку → Options → поставить галку Upgrade (НЕ Install!)
3. Upgrade → перезапишет MBR + служебный раздел НАЧИСТО:
   фейковый bootx64.efi, старый shim, Boot\, EFI\Microsoft, старый серт —
   ВСЁ сотрётся само; файлы ISO на большом разделе НЕ пострадают
4. Руками файлы разных версий венты НЕ СМЕШИВАТЬ: цепочка
   shim→fbx64→grub→payload жёстко версии-зависима

ШАГ 2 — Secure Boot (первая загрузка после апгрейда):
1. Синий экран MokManager → OK
2. Enroll key from disk → выбрать на служебном разделе
   ENROLL_THIS_KEY_IN_MOKMANAGER.cer (новый, 1 420 Б — уже будет на флешке)
3. Continue → ввести пароль с экрана → Reboot
4. Старый ключ (CN=grub) в MOK можно потом Remove, но не обязательно

## ЕСЛИ КОСЯКИ ОСТАЛИСЬ ПОСЛЕ АПГРЕЙДА (дамп снимался с корня диска)

На большом разделе флешки добить руками (X: — его буква):
    rd /s /q X:\Boot
    rd /s /q X:\EFI\Microsoft
EFI\BOOT на большом разделе НЕ ТРОГАТЬ только если там оказался фейковый
bootx64.efi 3 010 464 Б — тогда удалить и его (на служебном разделе после
апгрейда будет родной BOOTX64.EFI 1 045 176 Б).
