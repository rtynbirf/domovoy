# reports/ — журналы событий для SLA-контуров роя

- `cra-events.jsonl` — уязвимостные события CRA-контура; пишется вручную или агентом
  при инцидентах (vulnerability alerts, OSV-сверка). Заранее НЕ создаётся — появится с первым событием.
- Формат события — одна строка JSON: `{"date":"YYYY-MM-DD","source":"откуда","summary":"суть"}`.
- Читает `tools/cra_sla.py` (workflow `.github/workflows/cra-sla.yml`, вторник 06:00 UTC):
  событие старше 24 ч без пломбы-реакции в SEALS.jsonl = 🔴 инцидент, гейт exit 1.
- Файл может отсутствовать — событий нет, контур 🟢.
