PHX-HUB v1.2 - единый центр управления системой + ДВИЖОК ПРОФИЛЕЙ
Проект H-PE11 // PHOENIX
====================================================

ЧТО ЭТО
Механизм в духе TweakHub, собранный на нативном PowerShell 5.1 + WPF:
ноль внешних зависимостей, ничего не устанавливает, один файл.
Твики реестра, профили одним кликом, скор безопасности, устройства и
MSI-режим, схемы питания, DNS, чистка мусора из Store, службы,
журнал с полным откатом любых изменений.

НОВОЕ В v1.2 - PHX PROFILE ENGINE
Движок внешних профилей: понимает плейбуки TweakHub 1.5.0
(Version=1, Steps Tweak/Script, builtin:/custom:) И родные PHX-профили.
Против TweakHub - четыре наших:

1) КОНСТИТУЦИЯ-СТРАЖ. Каждый шаг плейбука проверяется до исполнения.
   Шаги, ломающие HDD-конституцию, БЛОКИРУЮТСЯ с явной причиной:
   - отключение дефрагментации
   - отключение SysMain/Superfetch/Prefetcher
   - TRIM-твики (диск TRIM физически не поддерживает)
   - трогание кэша записи
   - отключение диска по питанию (disk timeout > 0)
   TweakHub исполняет всё подряд - PHX-HUB сначала думает.

2) DRY-RUN. Полный прогон плейбука без единой записи: ни реестр,
   ни журнал. Смотришь, что будет, - потом решаешь.

3) SHA256 профиля в журнале. Каждое применение фиксирует хеш файла
   плейбука - целостность проверяется всегда.

4) builtin-каталог TweakHub вшит в движок (22 твика из открытых
   исходников TweakService.cs): builtin:cpu_priority_separation,
   builtin:disable_telemetry, builtin:svchost-сплит и другие
   исполняются БЕЗ установленного TweakHub.
   Незнакомый builtin честно SKIP с причиной, а не молча.

БЭКПАП И ОТКАТ - как у TweakHub и лучше:
- бэкап реестра перед КАЖДЫМ значением (reg export)
- откат прогона одним кликом (кнопка "Откат прогона")
- полный откат через ЖУРНАЛ И ОТКАТ (обратный порядок)
- точка восстановления перед профилем (по выбору)

КАК ЗАПУСТИТЬ
1. Двойной клик по PHX-HUB-LAUNCH.bat
2. Подтвердить UAC (иначе будет режим "только просмотр")
Всё. Бат и PS1 должны лежать в одной папке.

КАК ПРОГНАТЬ ПЛЕЙБУК TWEAKHUB ЧЕРЕЗ ДВИЖОК v1.1
1. Раздел ПРОФИЛИ -> кнопка "Импорт плейбука"
2. Выбрать *.json (например PHX-OPTIMAL-TUNING.tweakhub-playbook.json)
3. Прочитать сводку: SHA256, сколько шагов к исполнению,
   сколько БЛОК (и за что)
4. "Шаги" - полный список с пометками [ok]/[skip]/[БЛОК]
5. "DRY-RUN" - прогон без изменений
6. "ПРИМЕНИТЬ ПРОФИЛЬ" - бэкапы + журнал + точка восстановления (по выбору)
7. "Откат прогона" - вернуть всё из бэкапов, если что-то не понравилось

ПОДДЕРЖИВАЕМЫЕ ФОРМАТЫ ПРОФИЛЕЙ
- Плейбук TweakHub 1.5.0: {"Version":1,"Playbook":{...},"CustomTweaks":[],"CustomScripts":[]}
  Type 0 (Tweak: builtin:<slug> / custom:<id>) и Type 2 (Script: PowerShell inline)
  Type 1 (winget) - SKIP с подсказкой
- PHX-профиль: {"ver":"1.x","tweaks":[],"appx":[],"services":[]}
  (id из каталога PHX-HUB, службы - только из безопасного списка)
- Каталог профилей: %ProgramData%\PHX-HUB\profiles (карточки с применением)

ПРАВИЛА БЕЗОПАСНОСТИ
- Перед каждым изменением реестра ключ автоматически экспортируется
  в %ProgramData%\PHX-HUB\backup\<группа>\<ключ>.reg
- Каждая операция пишется в журнал %ProgramData%\PHX-HUB\journal.jsonl
- Откат одной группы или всего сразу - раздел ЖУРНАЛ И ОТКАТ
- Массовые операции предлагают точку восстановления
- Удаление приложений - только для текущего пользователя,
  возврат - из Microsoft Store
- Службы - только смена типа запуска, прежний тип в журнале
- Службы из профилей - только из безопасного пресета (список в коде)

ОТЛИЧИЯ ОТ TWEAKHUB (PrimeBuild-pc)
- 152 КБ против 70 МБ рантайма .NET
- Нулевые зависимости: только то, что уже есть в Windows
- Конституция-страж: HDD-вредные шаги БЛОКИРУЮТСЯ, а не исполняются
- DRY-RUN без записи
- Обратный порядок полного отката + reg-бэкапы до каждой записи
- Verify после прогона: сверка реестра по байтам (урок 0xFFFFFFFF)
- Русский интерфейс из коробки
