# ФЕНИКС-11 // PHOENIX-11 — БРЕНДБУК

## Имя
**ФЕНИКС-11** / международное написание **PHOENIX-11**.
Цифра 11 — Windows 11 (база WinPE 11 26H2) и первый уровень возрождения.

Почему ФЕНИКС: старый ноут Хозяина пал под бомбёжками. Из его пепла вылупилась
сборка, задача которой — поднимать мёртвые машины. Бренд = история проекта,
а не выдумка маркетолога. Даже Phoenix Technologies (тот самый BIOS) пусть
завидует: мы возрождаем то, что их BIOS не смог разбудить.

## Слоган
> **Встаёт из пепла. Поднимает другие.**

Технический вариант: *Rise. Repair. Repeat.*

## Легенда (для пункта [F] консоли)
```
Старый ноут пал под бомбёжками. Из его пепла
вылупился ФЕНИКС-11 — сборка, которая оживляет машины.
```

## Арт
`brand/phoenix_art.png` — жар-птица из живого огня и искр на чёрном дыму
(генеративный арт, 1344x768). Производные:
- `brand/PHOENIX-11_wallpaper.png` — плоская версия с логотипом (для репы/README)
- `sources\background.bmp` (1024x768 BMP, затемнён) — фон PE при загрузке
- `winpe.jpg` (1920x1080) — обои рабочего стола PE

Текст на арте наносится кодом (`scripts/make_wallpaper.py`), не генератором —
чтобы буквы были честными.
