## 3. Порядок применения (исполнить строго по шагам)

1. Скачать `PHX-OPTIMAL-KIT.zip` из релиза `phx-optimal-v1.0`, сверить SHA256 с таблицей §5.
2. Распаковать. Запустить `TweakHub.exe` **от администратора** (флаг portable уже внутри архива).
3. **ФАЗА 1 — TUNING (один раз):** Плейбуки → Импорт → `PHX-OPTIMAL-TUNING.tweakhub-playbook.json` → Применить → **ребут**.
   Что внутри: планировщик Win32PrioritySeparation `0x26`, SystemResponsiveness=10, svchost-сплит off, телеметрия/реклама/AI-политики 26H2 off, FSO off, GameDVR off, анимации/прозрачность off и сопутствующие облегчения под 2 ядра / 8 ГБ / HDD.
4. **ФАЗА 2 — MAINTENANCE (раз в 1–2 месяца):** импорт `PHX-OPTIMAL-MAINTENANCE.tweakhub-playbook.json` → очистка/обслуживание (WinSxS и пр., 15–60 мин, не прерывать).
5. Откат: TweakHub сам бэкапит реестр перед каждым шагом; дополнительно перед ПЕРВЫМ применением — точка восстановления вручную.
6. **АЛЬТЕРНАТИВА БЕЗ TWEAKHUB — PHX-HUB v1.2:** скачать `PHX-HUB-v1.2.zip` из релиза `phx-hub-v1.2`, распаковать, `PHX-HUB-LAUNCH.bat` → UAC → ПРОФИЛИ → «Импорт плейбука» → `PHX-OPTIMAL-TUNING.tweakhub-playbook.json` → читать сводку (SHA256, шаги, БЛОКи) → «Шаги» → **DRY-RUN** → «ПРИМЕНИТЬ ПРОФИЛЬ» (точка восстановления предложится сама). Откат — «Откат прогона» одним кликом. Наши плюсы: Конституция-страж не даст исполнить шаги, ломающие HDD-конституцию, DRY-RUN показывает всё заранее, builtin-шаги TweakHub исполняются без установленного TweakHub.
7. **КАРТА СТАНЦИИ (v1.3, закон Хозяина §9):** перед и после любых изменений — раздел КАРТА → «СНЯТЬ КАРТУ». Сводка в окне: ТРЕВОГИ конституции (SysMain Disabled, Prefetcher=0, defrag off — с командами возврата), дрейф с прошлой карты (что появилось/исчезло/сменилось). Файлы карт — JSON для агента проекта: карта снимается Хозяином и разбирается агентом вместо догадок.

## 4. HDD-конституция (нарушать ЗАПРЕЩЕНО)

Диск станции — HDD с пластиной, а не SSD. Поэтому:

- **Дефрагментацию НЕ отключать** — HDD её ждёт (по расписанию Windows).
- **SysMain / Prefetch НЕ отключать** — на этом HDD они ПОМОГАЮТ. (Сейчас SysMain остановлен — если запуск программ покажется вялым, вернуть в авто: `sc config SysMain start=auto`.)
- **Кэш записи не трогать.**
- **Диск от питания не отключать** (usbselect/отключение HDD через N минут — off).
- **TRIM-твики не применять** — TRIM на этом диске не поддерживается физически.

Контроль комплекта: `rg "sysmain|superfetch|prefetch|defrag|trim"` по обоим плейбукам = **0 совпадений** (проверено 28.10.2026).

## 9. КАРТА ТЕРРИТОРИИ (методология Хозяина — закон)

Закон Хозяина: прежде чем что-либо делать в системе=среде=враг — изучить её ДОСКОНАЛЬНО. На руках всегда должна быть КАРТА территории.

- **Карта железа** — что за оборудование и его реальные лимиты: CPU, плата, память, GPU, диск (SMART), сеть, BIOS, датчики.
- **Карта системы** — что за ОС поверх железа: билд, службы и их состояния, драйверы с версиями, автозагрузка, задачи, процессы, установленный софт, сеть.
- **Полная карта = соединение двух карт.** Только после соединения карт — любые действия (твики, установки, чистки). После каждого этапа действий карта снимается заново: свежий срез подтверждает результат и ловит отклонения.

Механизм карты: **AIDA64** («Мастер отчётов», полный текстовый отчёт). Карты проекта:

## 10. ЛАФХАК УСТАНОВКИ: NETSYS (закон Хозяина — «мотай на ус»)

Факт: ВСЕ ISO проекта падали при установке с ошибкой NETSYS (сетевая подсистема) — включая финальный PHOENIX v1.3.

- **Причина:** родной лаунчер Windows при установке лезет ПРЯМО В СЕТЬ (корпоративная шлюха — телеметрия/сетевые проверки во время развёртывания). На этой станции это роняет установку.
- **Решение (проверено Хозяином):** при ВЫДЁРГНУТОМ сетевом шнуре установка проходит успешно.
- **Канон установки (вшивать в каждую будущую инструкцию/ISO проекта):**
  1. Сетевой шнур — ВЫДЕРНУТЬ до старта установки.
  2. Установить систему (лансер не лезет в сеть — NETSYS не падает).
  3. Установить ВСЕ сетевые драйверы (Realtek RTL8168/8111 GbE).
  4. Воткнуть шнур. Итог: система с 27.10.2026 ни разу не падала (0 BSOD, 99.85% — карта Report.txt).
