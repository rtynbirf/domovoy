    C:\PHX и запускается ТОЛЬКО АУДИТ + ОТЧЁТ-ПЛАН. Ничего не применяется!

КАК СТАВИТЬ (маршрут B1 - как у WILLIAM v2, проверен на твоей станции)
----------------------------------------------------------------------
 1. Склей части ISO обратно (если качал частями):
      copy /b PHOENIX-ALPHA-0.1.iso.part00 + ...part01 + ...part02 +
              ...part03 + ...part04 PHOENIX-ALPHA-0.1.iso
    (или в PowerShell: cmd /c copy /b ...)
    Сверь SHA256 с SHA256SUMS (certutil -hashfile PHOENIX-ALPHA-0.1.iso SHA256).
 2. Запиши на флешку через Rufus: схема MBR + файловая система NTFS
    (станция CSM-only; UEFI-загрузчик в образе тоже остался - гибрид).
 3. Загрузись с флешки. Дальше:
      - выбери язык/издание (Pro один индекс - выберется сам);
      - ВЫБЕРИ ДИСК ВРУЧНУЮ (авто-вайпа нет);
      - установка пройдёт сама, OOBE почти пустой, вход под 6orman.

ПОРЯДОК ИСПЫТАНИЯ (что сделать руками)
--------------------------------------
 1. PHOENIX-CONTROL -> [2] REPORT (Balanced): посмотри ПЛАН (ничего не
    применено). Проверь, что детекции вменяемы (диск/GPU/RAM).
 2. Реши профиль:
      [3] Safe        - только телеметрия/WU-Security/AI/рестор-пойнт;
      [4] Balanced    - Safe + CPU/сеть/игра/отзывчивость + Light-деблоат;
      [5] Performance - Balanced + Default-деблоат + QoL;
      [6] PrivacyMax  - телеметрия + Edge-политики + Default-деблоат.
    Для станции 6ORMAN (Celeron N3350, 4 ГБ) первая ALPHA - РЕКОМЕНДУЮ [4].
 3. После Apply: ребут руками, поживи день-два. Если что-то не так:
      [7] RESTORE - полный откат по журналу (reg+сервисы+задачи+Appx).
    Плюс в C:\PHX\bin\PHX_TWEAKBACKUP_*\ лежит rollback.ps1 и
    reg_export\*.reg - откат двойной страховкой.
 4. Отправь Хозяину:
      - C:\PHX\reports\PHX-HW-REPORT.txt (целиком);
      - последний PHX_TWEAKPACK_*.log с рабочего стола (целиком);
      - одним словом: что ощущаешь (скорость/глюки/что бесит).
    По этим данным соберём v2.1 - профиль под ТВОЁ железо.
